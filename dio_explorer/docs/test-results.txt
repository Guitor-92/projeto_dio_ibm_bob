# ⚔️ Desafio de Código — Java | Nível: intermediário

---

## 📋 Enunciado

**Agenda de Contatos com Busca**

Implemente uma agenda de contatos em Java que permita:
- Adicionar um contato com nome e telefone (rejeite nomes duplicados)
- Buscar contatos pelo nome (busca parcial, case-insensitive)
- Listar todos os contatos em ordem alfabética

Use as estruturas de dados adequadas para maximizar eficiência.

---

## 📥 Entrada Esperada

Sequência de comandos em stdin: ADD <nome> <telefone>, SEARCH <termo>, LIST

**Exemplo de entrada:**
```
ADD João 99999-0001
ADD Ana 88888-0002
ADD João 77777-0003
SEARCH jo
LIST
```

---

## 📤 Saída Esperada

**Exemplo de saída:**
```
Contato adicionado: João
Contato adicionado: Ana
Erro: contato 'João' já existe
Resultados: João (99999-0001)
Ana (88888-0002)
João (99999-0001)
```

---

## ⚙️ Restrições e Regras

- Não use banco de dados ou persistência em arquivo
- Nomes duplicados devem ser rejeitados com mensagem de erro
- A busca deve ser case-insensitive

---

## 💡 Dicas

> 💭 HashMap é ideal para armazenar e acessar contatos por nome em O(1)
> 💭 Use TreeMap se quiser ordenação automática por chave

---

## 🧩 Critérios de Avaliação

- [ ] O código resolve o problema corretamente
- [ ] Os casos extremos (edge cases) são tratados
- [ ] O código está bem organizado e legível
- [ ] Utiliza a estrutura de dados adequada e trata duplicatas corretamente
